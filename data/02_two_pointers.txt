给定一个数组 nums，编写一个函数将所有 0 移动到数组的末尾，同时保持非零元素的相对顺序。

请注意，必须在不复制数组的情况下原地对数组进行操作。

示例 1：
输入：nums = [0,1,0,3,12]
输出：[1,3,12,0,0]

示例 2：
输入：nums = [0]
输出：[0]

提示：
1 <= nums.length <= 10^4
-2^31 <= nums[i] <= 2^31 - 1

进阶：你能尽量减少完成的操作次数吗？
给定一个数组 nums，编写函数将所有 0 移动到数组末尾，同时保持非零元素的相对顺序。
必须在不复制数组的情况下原地对数组进行操作。
示例：输入 [0,1,0,3,12] → 输出 [1,3,12,0,0]。
@@SOLUTION: 方法一：快慢双指针交换（推荐）
@@IDEA
快慢双指针：slow 指向下一个非零数应放的位置，fast 扫描数组，遇到非零就与 slow 交换并右移 slow。交换保证非零元素相对顺序不变。时间 O(n)，空间 O(1)。
@@JAVA
class Solution {
    public void moveZeroes(int[] nums) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != 0) {
                int t = nums[slow]; nums[slow] = nums[fast]; nums[fast] = t;
                slow++; // 下一个非零元素的位置
            }
        }
    }
}

class Solution {
    public void moveZeroes(int[] nums) {
        int k = 0;
        for (int x : nums) {
            if (x != 0) nums[k++] = x; // 非零前移覆盖
        }
        while (k < nums.length) {
            nums[k++] = 0;             // 尾部补零
        }
    }
}

@@SOLUTION: 方法三：零元素冒泡后移
@@IDEA
冒泡思路：遇到 0 就向右找第一个非零数换过来，0 不断往后沉，非零自然前移且保持相对顺序。最坏 O(n²)，仅作对照理解。

class Solution {
    public void moveZeroes(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (nums[i] != 0) continue;
            int j = i + 1;                 // 找 i 之后第一个非零
            while (j < n && nums[j] == 0) j++;
            if (j == n) break;             // 后面全是 0
            nums[i] = nums[j];             // 换过来
            nums[j] = 0;
        }
    }
}

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

示例 1：
输入：height = [1,8,6,2,5,4,8,3,7]
输出：49
解释：垂直线代表输入数组 [1,8,6,2,5,4,8,3,7]。在此情况下，能够容纳水（表示为蓝色部分）的最大值为 49。

示例 2：
输入：height = [1,1]
输出：1

提示：
2 <= n <= 10^5
0 <= height[i] <= 10^4
给定一个长度为 n 的整数数组 height，其中 height[i] 表示第 i 条垂线的高度。选择两条线共同构成容器，求容器可以容纳最多的水。
说明：容器面积 = min(两线高度) × (两线下标间距)，不可倾斜容器。

@@SOLUTION: 方法一：双指针（推荐）
@@IDEA
首尾双指针向中间收缩：面积由较矮一端决定，移动较高的一端不可能让面积变大，所以每轮固定移动较矮的一端。关键在于理解这个「移动矮端不丢最优解」的贪心证明。时间 O(n)。
@@JAVA
class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1, best = 0;
        while (l < r) {
            int area = Math.min(height[l], height[r]) * (r - l);
            best = Math.max(best, area);
            if (height[l] < height[r]) l++; // 移动较矮的一端
            else r--;
        }
        return best;
    }
}

@@IDEA
单调栈视角：维护高度递减的下标栈，对每个 i 弹栈后栈顶就是它左侧最远的不矮于它的板，以 h[i] 为短板结算面积；正反各扫一遍覆盖两种情况。时间 O(n)，空间 O(n)。

class Solution {
    public int maxArea(int[] height) {
        int[] h = height, rev = height.clone();
        int best = scan(h);
        // 反转数组再扫一遍：等价于「每个右板找左侧最远高板」
        for (int l = 0, r = rev.length - 1; l < r; l++, r--) {
            int t = rev[l]; rev[l] = rev[r]; rev[r] = t;
        }
        return Math.max(best, scan(rev));
    }
    // 单调递减栈：对每个 i，栈顶是 i 左侧最远的 >= h[i] 的下标
    private int scan(int[] h) {
        int best = 0;
        Deque<Integer> mono = new ArrayDeque<>(); // 下标，高度递减
        for (int i = 0; i < h.length; i++) {
            while (!mono.isEmpty() && h[mono.peek()] < h[i]) mono.pop();
            if (!mono.isEmpty()) {
                best = Math.max(best, h[i] * (i - mono.peek()));
            }
            mono.push(i);
        }
        return best;
    }
}

        def scan(h: List[int]) -> None:
            nonlocal best
            mono = []  # 下标，高度递减

                mono.append(i)

        scan(height[::-1])  # 反向再扫一遍
        return best

注意：答案中不可以包含重复的三元组。

示例 1：
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0；nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0；nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0。不同的三元组是 [-1,0,1] 和 [-1,-1,2]。注意，输出的顺序和三元组的顺序并不重要。

示例 2：
输入：nums = [0,1,1]
输出：[]

示例 3：
输入：nums = [0,0,0]
输出：[[0,0,0]]

提示：
3 <= nums.length <= 3000
-10^5 <= nums[i] <= 10^5
给你一个整数数组 nums，判断是否存在三元组 [nums[i], nums[j], nums[k]] 满足三数之和为 0 且下标互不相同。
返回所有和为 0 且不重复的三元组。
示例：nums = [-1,0,1,2,-1,-4] → 输出 [[-1,-1,2],[-1,0,1]]。
@@SOLUTION: 方法一：排序 + 双指针（推荐）
@@IDEA
先排序让相同元素相邻，枚举第一个数 a（跳过重复、大于 0 剪枝），剩余两数用左右双指针收缩；命中后两侧各跳过重复值再继续。去重是本题最大易错点。时间 O(n²)。
@@JAVA
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums);
        List<List<Integer>> res = new ArrayList<>();
        int n = nums.length;
        for (int i = 0; i < n - 2; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue; // 第一个数去重
            if (nums[i] > 0) break; // 最小数已大于 0
            int l = i + 1, r = n - 1;
            while (l < r) {
                int sum = nums[i] + nums[l] + nums[r];
                if (sum < 0) l++;
                else if (sum > 0) r--;
                else {
                    res.add(Arrays.asList(nums[i], nums[l], nums[r]));
                    while (l < r && nums[l] == nums[l + 1]) l++; // 左端去重
                    while (l < r && nums[r] == nums[r - 1]) r--; // 右端去重
                    l++; r--;
                }
            }
        }
        return res;
    }
}

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        Arrays.sort(nums); // 先排序便于去重
        Set<List<Integer>> seen = new HashSet<>();
        int n = nums.length;
        for (int i = 0; i < n - 1; i++) {
            if (i > 0 && nums[i] == nums[i - 1]) continue;
            Set<Integer> bag = new HashSet<>(); // 值集合
            for (int j = i + 1; j < n; j++) {
                int need = -nums[i] - nums[j];
                if (bag.contains(need)) {
                    seen.add(Arrays.asList(nums[i], need, nums[j]));
                }
                bag.add(nums[j]);
            }
        }
        return new ArrayList<>(seen);
    }
}

@@DIFF: 困难
@@CATEGORY: 双指针
@@TAGS: 栈;数组;双指针;动态规划
@@URL: https://leetcode.cn/problems/trapping-rain-water/
@@DESC
给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

示例 1：
输入：height = [0,1,0,2,1,0,1,3,2,1,2,1]
输出：6
解释：上面是由数组 [0,1,0,2,1,0,1,3,2,1,2,1] 表示的高度图，在这种情况下，可以接 6 个单位的雨水（蓝色部分表示雨水）。

示例 2：
输入：height = [4,2,0,3,2,5]
输出：9

提示：
1 <= height.length <= 2 * 10^4
0 <= height[i] <= 10^5

进阶：O(n) 时间、O(1) 空间的解法？
给定 n 个非负整数表示柱高（宽度为 1），求按此排列的柱子能接多少雨水。
示例：height = [0,1,0,2,1,0,1,3,2,1,2,1] → 输出 6。
@@SOLUTION: 方法一：双指针（推荐，O(1) 空间）
@@IDEA
每个位置能接的水 = min(左侧最大, 右侧最大) - 自身高度。左右双指针配合 lMax/rMax：哪侧最大值更小，哪侧的位置水量就已确定，可以立即结算。O(n) 时间、O(1) 空间的最优解。
@@JAVA
class Solution {
    public int trap(int[] height) {
        int l = 0, r = height.length - 1;
        int lMax = 0, rMax = 0, water = 0;
        while (l < r) {
            lMax = Math.max(lMax, height[l]);
            rMax = Math.max(rMax, height[r]);
            if (lMax < rMax) {            // 左侧瓶颈已确定
                water += lMax - height[l++];
            } else {                      // 右侧瓶颈已确定
                water += rMax - height[r--];
            }
        }
        return water;
    }
}

@@IDEA
先预处理两个数组：lmax[i] 是 i 左侧最大高度，rmax[i] 是右侧最大高度，再逐位结算 min(lmax[i], rmax[i]) - h[i]。思路最直观，是理解接雨水的第一步。时间 O(n)，空间 O(n)。

class Solution {
    public int trap(int[] height) {
        int n = height.length;
        int[] lmax = new int[n], rmax = new int[n];
        lmax[0] = height[0];
        for (int i = 1; i < n; i++) lmax[i] = Math.max(lmax[i - 1], height[i]);
        rmax[n - 1] = height[n - 1];
        for (int i = n - 2; i >= 0; i--) rmax[i] = Math.max(rmax[i + 1], height[i]);
        int water = 0;
        for (int i = 0; i < n; i++) {
            water += Math.min(lmax[i], rmax[i]) - height[i]; // 逐位结算
        }
        return water;
    }
}

@@SOLUTION: 方法三：单调栈（按层接水）
@@IDEA
按「层」接水的视角：维护高度递减栈，遇到更高柱时弹出栈顶作为凹槽底，横向一层层结算（宽 = 当前下标-新栈顶-1）。时间 O(n)，空间 O(n)。
@@JAVA
class Solution {
    public int trap(int[] height) {
        Deque<Integer> stack = new ArrayDeque<>(); // 下标，高度递减
        int water = 0;
        for (int i = 0; i < height.length; i++) {
            while (!stack.isEmpty() && height[stack.peek()] < height[i]) {
                int bottom = stack.pop();          // 凹槽底
                if (stack.isEmpty()) break;
                int left = stack.peek();
                int w = i - left - 1;              // 槽宽
                int h = Math.min(height[left], height[i]) - height[bottom];
                water += w * h;                    // 横向一层结算
            }
            stack.push(i);
        }
        return water;
    }
}

class Solution:
    def trap(self, height: List[int]) -> int:
        stack = []  # 下标，高度递减
        water = 0
        for i, h in enumerate(height):
            while stack and height[stack[-1]] < h:
                bottom = stack.pop()   # 凹槽底
                if not stack:
                    break
                left = stack[-1]
                w = i - left - 1       # 槽宽
                hh = min(height[left], h) - height[bottom]
                water += w * hh        # 横向一层结算
            stack.append(i)
        return water
