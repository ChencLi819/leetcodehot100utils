给你一个整数数组 nums，找出和最大的连续子数组（至少含一个元素）并返回其和。
示例：nums = [-2,1,-3,4,-1,2,1,-5,4] → 输出 6（子数组 [4,-1,2,1]）。
@@SOLUTION: 方法一：Kadane 动态规划（推荐）
@@IDEA
Kadane 算法：dp[i] 表示以 i 结尾的最大子数组和，转移 = max(nums[i], dp[i-1]+nums[i])——前面的累计为正就带上，为负就重新开始。滚动变量即可，O(n)/O(1)。
@@JAVA
class Solution {
    public int maxSubArray(int[] nums) {
        int best = nums[0], cur = nums[0];
        for (int i = 1; i < nums.length; i++) {
            cur = Math.max(nums[i], cur + nums[i]); // 延续或重新开始
            best = Math.max(best, cur);
        }
        return best;
    }
}

@@SOLUTION: 方法二：前缀和（最大差值）
@@IDEA
换视角：子数组和 = 两个前缀和之差。遍历时维护历史最小前缀和 minPre，当前前缀和 pre 减它就是以当前结尾的最大子段和。O(n)/O(1)，与 Kadane 等价。
@@JAVA
class Solution {
    public int maxSubArray(int[] nums) {
        int best = Integer.MIN_VALUE, pre = 0, minPre = 0;
        for (int x : nums) {
            pre += x;                                  // 当前前缀和
            best = Math.max(best, pre - minPre);       // 减历史最小前缀
            minPre = Math.min(minPre, pre);
        }
        return best;
    }
}

@@IDEA
分治：每个区间维护（总和、最大前缀、最大后缀、最大子段和）四元组，合并时跨中点情况 = 左后缀 + 右前缀。O(n)，可扩展成支持单点修改的线段树做法。

class Solution {
    public int maxSubArray(int[] nums) {
        return divide(nums, 0, nums.length - 1)[3];
    }
    // 返回 {区间和, 最大前缀, 最大后缀, 最大子段和}
    private int[] divide(int[] a, int l, int r) {
        if (l == r) return new int[]{a[l], a[l], a[l], a[l]};
        int mid = (l + r) / 2;
        int[] L = divide(a, l, mid), R = divide(a, mid + 1, r);
        int[] res = new int[4];
        res[0] = L[0] + R[0];                                  // 总和
        res[1] = Math.max(L[1], L[0] + R[1]);                  // 前缀
        res[2] = Math.max(R[2], R[0] + L[2]);                  // 后缀
        res[3] = Math.max(Math.max(L[3], R[3]), L[2] + R[1]);  // 跨中点
        return res;
    }
}

            ls, lp, lsf, lb = divide(l, mid)
            rs, rp, rsf, rb = divide(mid + 1, r)

                    max(rsf, rs + lsf),

@@IDEA

class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]); // 按左端点排序
        List<int[]> res = new ArrayList<>();
        for (int[] cur : intervals) {
            if (!res.isEmpty() && cur[0] <= res.get(res.size() - 1)[1]) {
                int[] last = res.get(res.size() - 1);
                last[1] = Math.max(last[1], cur[1]); // 合并
            } else {
                res.add(cur);
            }
        }
        return res.toArray(new int[0][]);
    }
}

class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
        int idx = -1; // 已归并段末尾
        for (int[] cur : intervals) {
            if (idx >= 0 && cur[0] <= intervals[idx][1]) {
                intervals[idx][1] = Math.max(intervals[idx][1], cur[1]);
            } else {
                intervals[++idx] = cur; // 新段写回原数组
            }
        }
        return Arrays.copyOf(intervals, idx + 1);
    }
}

@@IDEA
扫描线：每个区间产生「起点 +1、终点+1 位置 -1」两个事件，按坐标排序扫描，覆盖数从 0 变正开段、归零闭段。可自然推广到多个区间的并/交问题。O(n log n)。

class Solution {
    public int[][] merge(int[][] intervals) {
        // 事件：起点 +1，终点下一位 -1
        List<int[]> events = new ArrayList<>();
        for (int[] it : intervals) {
            events.add(new int[]{it[0], 1});
            events.add(new int[]{it[1] + 1, -1});
        }
        events.sort((a, b) -> a[0] != b[0] ? a[0] - b[0] : a[1] - b[1]);
        List<int[]> res = new ArrayList<>();
        int cover = 0, start = 0;
        for (int[] e : events) {
            if (cover == 0) start = e[0]; // 从 0 变正：开段
            cover += e[1];
            if (cover == 0) {             // 归零：闭段
                res.add(new int[]{start, e[0] - 1});
            }
        }
        return res.toArray(new int[0][]);
    }
}

给定一个整数数组 nums，将数组中的元素向右轮转 k 个位置，其中 k 是非负数。要求使用空间复杂度为 O(1) 的原地算法。

@@SOLUTION: 方法一：三次反转（推荐）
@@IDEA
经典三次反转：先整体反转，再分别反转前 k 个和后 n-k 个。正确性基于「轮转 = 两段交换位置」，先 k %= n 防越界。O(n) 时间、O(1) 空间的标准解。
@@JAVA
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        reverse(nums, 0, n - 1); // 整体反转
        reverse(nums, 0, k - 1); // 前 k 个
        reverse(nums, k, n - 1); // 后 n-k 个
    }
    private void reverse(int[] nums, int l, int r) {
        while (l < r) {
            int t = nums[l]; nums[l] = nums[r]; nums[r] = t;
            l++; r--;
        }
    }
}

@@IDEA
环形替换：从起点出发把元素一步搬到 (i+k)%n 的位置，被顶掉的元素继续搬，回到起点后换下一个环，直到搬完 n 个元素。O(n)/O(1)，易错点是环的个数要数对。
@@JAVA
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k %= n;
        int count = 0; // 已搬移的元素个数
        for (int start = 0; count < n; start++) {
            int cur = start, prevVal = nums[start];
            do {
                int next = (cur + k) % n;
                int t = nums[next];
                nums[next] = prevVal; // 一步到位
                prevVal = t;
                cur = next;
                count++;
            } while (cur != start); // 回到起点换下一个环
        }
    }
}

        int[] copy = nums.clone();
        // 后 k 段放前面，前 n-k 段放后面

@@JAVA
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];
        answer[0] = 1;
        for (int i = 1; i < n; i++) {       // 左侧前缀乘积
            answer[i] = answer[i - 1] * nums[i - 1];
        }
        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {  // 乘上右侧后缀乘积
            answer[i] *= suffix;
            suffix *= nums[i];
        }
        return answer;
    }
}

        int[] prefix = new int[n], suffix = new int[n];
        prefix[0] = 1;
        for (int i = 1; i < n; i++) prefix[i] = prefix[i - 1] * nums[i - 1];
        suffix[n - 1] = 1;
        for (int i = n - 2; i >= 0; i--) suffix[i] = suffix[i + 1] * nums[i + 1];

        for (int i = 0; i < n; i++) {
            answer[i] = prefix[i] * suffix[i]; // 左乘积 × 右乘积

        return answer;

class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length, zeros = 0, total = 1;
        for (int x : nums) {
            if (x == 0) zeros++;
            else total *= x; // 非零数乘积
        }
        int[] answer = new int[n];
        if (zeros >= 2) return answer;             // 全 0
        for (int i = 0; i < n; i++) {
            if (zeros == 1) {
                answer[i] = (nums[i] == 0) ? total : 0; // 唯一零位
            } else {
                answer[i] = total / nums[i];       // 用除法（题目禁用）
            }
        }
        return answer;
    }
}

提示：

-2^31 <= nums[i] <= 2^31 - 1
给你一个未排序的整数数组 nums，请找出其中没有出现的最小正整数。要求实现 O(n) 时间、O(1) 空间。
示例：nums = [3,4,-1,1] → 输出 2；nums = [7,8,9,11,12] → 输出 1。
@@SOLUTION: 方法一：原地哈希（鸽笼置换，推荐）
@@IDEA
鸽笼原理：答案必在 [1, n+1] 内。把每个值 v∈[1,n] 循环交换到下标 v-1（原地哈希），最后第一个 nums[i] != i+1 的位置就是答案。O(n) 时间、O(1) 空间。
@@JAVA
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            // 把值 v 放到下标 v-1，循环处理链上交换
            while (nums[i] >= 1 && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
                int j = nums[i] - 1;
                int t = nums[j]; nums[j] = nums[i]; nums[i] = t;
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] != i + 1) return i + 1; // 第一个未归位处
        }
        return n + 1;
    }
}

                return i + 1
        return n + 1
@@SOLUTION: 方法二：打标记（正负号作布尔数组）
@@IDEA
两遍打标记：先把非正数替换成 n+1；再对每个 |v|≤n 的值把 nums[v-1] 取负作为「v 出现过」的标记；第一个仍为正的位置即答案。O(n)/O(1)。
@@JAVA
class Solution {
    public int firstMissingPositive(int[] nums) {
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            if (nums[i] <= 0) nums[i] = n + 1; // 无关值统一置大
        }
        for (int i = 0; i < n; i++) {
            int v = Math.abs(nums[i]);
            if (v <= n && nums[v - 1] > 0) {
                nums[v - 1] = -nums[v - 1];    // 标记 v 出现过
            }
        }
        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) return i + 1;     // 未被标记处
        }
        return n + 1;
    }
}

@@SOLUTION: 方法三：哈希集合（满足时间不满足空间）
@@IDEA
把所有正数放进 HashSet，从 1 开始向上问「在不在集合里」，第一个不在的就是答案。O(n)/O(n)，最易理解，但不满足 O(1) 空间要求。
@@JAVA
class Solution {
    public int firstMissingPositive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int x : nums) {
            if (x > 0) set.add(x); // 只关心正数
        }
        int ans = 1;
        while (set.contains(ans)) ans++; // 从 1 向上找
        return ans;
    }
}

class Solution:
    def firstMissingPositive(self, nums: List[int]) -> int:
