@@DIFF: 简单
@@CATEGORY: 贪心算法

@@DESC
给定一个数组 prices，它的第 i 个元素 prices[i] 表示一支给定股票第 i 天的价格。

你只能选择某一天买入这只股票，并选择在未来的某一个不同的日子卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 0。

示例 1：
输入：prices = [7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5。注意利润不能是 7-1 = 6，因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。

示例 2：
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成，所以最大利润为 0。

提示：
1 <= prices.length <= 10^5
0 <= prices[i] <= 10^4
给定数组 prices，第 i 个元素是第 i 天的股票价格。只能选择某一天买入、之后某一天卖出，求最大利润；无法获利返回 0。
示例：prices = [7,1,5,3,6,4] → 输出 5（第 2 天买、第 5 天卖）。
@@SOLUTION: 方法一：一次扫描记录历史最低（推荐）
@@IDEA
一次扫描：维护历史最低价 minPrice，当天卖出的利润 = 当天价 - minPrice，取全局最大。O(n)/O(1)，贪心入门题。
@@JAVA
class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE, best = 0;
        for (int p : prices) {
            minPrice = Math.min(minPrice, p);    // 历史最低
            best = Math.max(best, p - minPrice); // 今天卖的利润
        }
        return best;
    }
}

class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int hold = -prices[0], sold = 0; // 持股 / 不持股
        for (int i = 1; i < n; i++) {
            sold = Math.max(sold, hold + prices[i]); // 今天卖或不动作
            hold = Math.max(hold, -prices[i]);       // 今天买或不动作
        }
        return sold; // 最终不持股收益最大
    }
}

class Solution {
    public int maxProfit(int[] prices) {
        int n = prices.length;
        int[] suffixMax = new int[n];
        suffixMax[n - 1] = prices[n - 1];
        for (int i = n - 2; i >= 0; i--) {        // 后缀最高价
            suffixMax[i] = Math.max(suffixMax[i + 1], prices[i]);
        }
        int best = 0;
        for (int i = 0; i < n; i++) {
            best = Math.max(best, suffixMax[i] - prices[i]); // 今天买的最优卖价
        }
        return best;
    }
}

给你一个非负整数数组 nums，你最初位于数组的第一个下标。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 true；否则，返回 false。

示例 1：
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1，然后再从下标 1 跳 3 步到达最后一个下标。

示例 2：
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0，所以永远不可能到达最后一个下标。

提示：
1 <= nums.length <= 10^4
0 <= nums[i] <= 10^5
给定非负整数数组 nums，最初位于第一个下标，每个元素表示该位置最多能跳的步数。判断是否能到达最后一个下标。
示例：nums = [2,3,1,1,4] → true；nums = [3,2,1,0,4] → false。
@@SOLUTION: 方法一：贪心最远可达（推荐）
@@IDEA
贪心最远可达：farthest = max(farthest, i+nums[i])；若 i 超出 farthest 说明当前位置不可达返回 false；farthest ≥ n-1 提前成功。O(n)/O(1)。
@@JAVA
class Solution {
    public boolean canJump(int[] nums) {
        int farthest = 0;
        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) return false;         // 当前不可达
            farthest = Math.max(farthest, i + nums[i]);
            if (farthest >= nums.length - 1) return true;
        }
        return true;
    }
}

@@IDEA
可达性 DP：dp[i] 表示 i 是否可达，由之前任意可达 j 且 j+nums[j] ≥ i 转移。O(n²)，直观但慢，作对照。

class Solution {
    public boolean canJump(int[] nums) {
        int n = nums.length;
        boolean[] dp = new boolean[n];
        dp[0] = true; // 起点可达
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && j + nums[j] >= i) { // 有可达位置能跳到 i
                    dp[i] = true;
                    break;
                }
            }
        }
        return dp[n - 1];
    }
}

        int needReach = nums.length - 1; // 当前必须可达的最左位置
        for (int i = nums.length - 2; i >= 0; i--) {
            if (i + nums[i] >= needReach) {
                needReach = i; // i 可达，成为新的必须点
            }
        }
        return needReach == 0;
    }
}

给定一个长度为 n 的 0 索引整数数组 nums。初始位置为 nums[0]。

每个元素 nums[i] 表示从索引 i 向后跳转的最大长度。换句话说，如果你在 nums[i] 处，你可以跳转到任意 nums[i + j] 处（0 <= j <= nums[i] 且 i + j < n）。
返回到达 nums[n - 1] 的最小跳跃次数。生成的测试用例可以到达 nums[n - 1]。

示例 1：
输入：nums = [2,3,1,1,4]
输出：2
解释：跳到最后一个位置的最小跳跃数是 2。从下标为 0 跳到下标为 1 的位置，跳 1 步，然后跳 3 步到达数组的最后一个位置。

示例 2：
输入：nums = [2,3,0,1,4]
输出：2

提示：
1 <= nums.length <= 10^4
0 <= nums[i] <= 1000
题目保证可以到达 nums[n-1]
给定非负整数数组 nums（保证可到达最后一个下标），返回到达最后一个下标的最少跳跃次数。
示例：nums = [2,3,1,1,4] → 输出 2（跳到下标 1，再一步到底）。
@@SOLUTION: 方法一：层次贪心（隐式 BFS，推荐）
@@IDEA
层次贪心（隐式 BFS）：curEnd 是当前层的最右边界，扫描中更新 farthest；i 触到 curEnd 时步数 +1 并把边界推到 farthest，覆盖终点即停。O(n)/O(1)。
@@JAVA
class Solution {
    public int jump(int[] nums) {
        int n = nums.length, steps = 0;
        int curEnd = 0, farthest = 0;
        for (int i = 0; i < n - 1; i++) {   // 不遍历最后一步
            farthest = Math.max(farthest, i + nums[i]);
            if (i == curEnd) {              // 走完当前层
                steps++;
                curEnd = farthest;
                if (curEnd >= n - 1) break;
            }
        }
        return steps;
    }
}

@@IDEA
显式 BFS：下标为节点，i 可跳到 [i+1, i+nums[i]]；逐层扩散计数，首次到达终点即最少步数。O(n)/O(n)，用图视角理解「最少跳数=最短层数」。
@@JAVA
class Solution {
    public int jump(int[] nums) {
        int n = nums.length;
        if (n == 1) return 0;
        boolean[] visited = new boolean[n];
        Deque<Integer> queue = new ArrayDeque<>();
        queue.offer(0);
        visited[0] = true;
        int steps = 0;
        while (!queue.isEmpty()) {
            steps++;
            int size = queue.size();
            for (int k = 0; k < size; k++) {
                int i = queue.poll();
                for (int j = i + 1; j <= Math.min(i + nums[i], n - 1); j++) {
                    if (j == n - 1) return steps;  // 首次到达
                    if (!visited[j]) {
                        visited[j] = true;
                        queue.offer(j);
                    }
                }
            }
        }
        return -1;
    }
}

class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26]; // 每个字母最后出现位置
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }
        List<Integer> res = new ArrayList<>();
        int start = 0, end = 0;
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);
            if (i == end) {          // 可以切一段
                res.add(i - start + 1);
                start = i + 1;
            }
        }
        return res;
    }
}

@@IDEA
区间合并视角：每个字母是区间 [首次出现, 最后出现]，排序后合并相交区间，每个合并区间即一个片段。O(n log n)（n 大时），另解视角。

class Solution {
    public List<Integer> partitionLabels(String s) {
        int[][] range = new int[26][2]; // 每字母 [首现, 末现]
        for (int[] r : range) { r[0] = -1; r[1] = -1; }
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            if (range[c][0] == -1) range[c][0] = i;
            range[c][1] = i;
        }
        List<int[]> intervals = new ArrayList<>();
        for (int[] r : range) {
            if (r[0] != -1) intervals.add(r);
        }
        intervals.sort((a, b) -> a[0] - b[0]); // 按起点排序
        List<Integer> res = new ArrayList<>();
        int start = intervals.get(0)[0], end = intervals.get(0)[1];
        for (int[] r : intervals) {
            if (r[0] > end) {           // 不相交：结算一段
                res.add(end - start + 1);
                start = r[0];
            }
            end = Math.max(end, r[1]);  // 合并
        }
        res.add(end - start + 1);
        return res;
    }
}

@@IDEA
集合完结判定：维护当前段内字母集合 active，字母最后一次出现后从集合移除；集合为空时说明段内全部完结，可以切分。O(n)/O(26)。

class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];
        for (int i = 0; i < s.length(); i++) last[s.charAt(i) - 'a'] = i;
        Set<Integer> active = new HashSet<>(); // 当前段内字母
        List<Integer> res = new ArrayList<>();
        int segStart = 0;
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            active.add(c);
            if (last[c] == i) active.remove(c); // 该字母在段内完结
            if (active.isEmpty()) {             // 段内全部完结 → 切分
                res.add(i - segStart + 1);
                segStart = i + 1;
            }
        }
        return res;
    }
}
