@@DESC
整数数组 nums 按升序排列，数组中的值 互不相同。

在传递给函数之前，nums 在预先未知的某个下标 k（0 <= k < nums.length）上进行了旋转，使数组变为 [nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]（下标 从 0 开始 计数）。例如，[0,1,2,4,5,6,7] 在下标 3 处经旋转后可能变为 [4,5,6,7,0,1,2]。

给你旋转后的数组 nums 和一个整数 target，如果 nums 中存在这个目标值 target，则返回它的下标，否则返回 -1。

你必须设计一个时间复杂度为 O(log n) 的算法。

示例 1：
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4

示例 2：
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1

示例 3：
输入：nums = [1], target = 0
输出：-1

提示：
1 <= nums.length <= 5000
-10^4 <= nums[i] <= 10^4
nums 中的每个值都 独一无二
题目数据保证 nums 在预先未知的某个下标上进行了旋转
-10^4 <= target <= 10^4

进阶：你可以想出 O(log n) 的解决方案吗？
给定二叉树的根节点 root，返回它的中序遍历（左 → 根 → 右）。
示例：root = [1,null,2,3] → 输出 [1,3,2]。
@@SOLUTION: 方法一：递归（推荐）
@@IDEA
递归三行：左子树遍历 → 访问根 → 右子树遍历。中序递归是所有二叉树题的基础模板。O(n)/O(h)。
@@JAVA
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        inorder(root, res);
        return res;
    }
    private void inorder(TreeNode node, List<Integer> res) {
        if (node == null) return;
        inorder(node.left, res);  // 左
        res.add(node.val);        // 根
        inorder(node.right, res); // 右
    }
}

@@SOLUTION: 方法二：迭代显式栈
@@IDEA
迭代显式栈：一路向左压栈，弹出访问后转向右子树；循环条件 cur != null || 栈非空。模拟系统栈行为，O(n)/O(h)，必须掌握的非递归写法。
@@JAVA
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            while (cur != null) {   // 一路向左压栈
                stack.push(cur);
                cur = cur.left;
            }
            cur = stack.pop();      // 访问栈顶
            res.add(cur.val);
            cur = cur.right;        // 转向右子树
        }
        return res;
    }
}

@@SOLUTION: 方法三：Morris 中序遍历（O(1) 空间）
@@IDEA
Morris 遍历：为每个节点找左子树的最右节点建立临时回链，访问完拆除，空间 O(1)。第一次到达建链转左、第二次到达拆链访问并转右。O(n)/O(1)。
@@JAVA
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        TreeNode cur = root;
        while (cur != null) {
            if (cur.left == null) {
                res.add(cur.val);       // 无左子树，直接访问
                cur = cur.right;
            } else {
                TreeNode pred = cur.left;
                while (pred.right != null && pred.right != cur) {
                    pred = pred.right;  // 左子树最右节点
                }
                if (pred.right == null) {
                    pred.right = cur;   // 建临时回链
                    cur = cur.left;
                } else {
                    pred.right = null;  // 拆链（第二次到达）
                    res.add(cur.val);
                    cur = cur.right;
                }
            }
        }
        return res;
    }
}

注意，数组 [a[0], a[1], a[2], ..., a[n-1]] 旋转一次 的结果为数组 [a[n-1], a[0], a[1], a[2], ..., a[n-2]]。

@@IDEA

class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        return 1 + Math.max(maxDepth(root.left), maxDepth(root.right));
    }
}

@@SOLUTION: 方法二：BFS 层序计数
@@IDEA
BFS 层序：每处理完一层深度 +1，队列空时的层数即最大深度。适合已经会层序模板的场景。O(n)/O(宽度)。
@@JAVA
class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        int depth = 0;
        while (!queue.isEmpty()) {
            int size = queue.size();
            for (int i = 0; i < size; i++) { // 遍历一整层
                TreeNode node = queue.poll();
                if (node.left != null) queue.offer(node.left);
                if (node.right != null) queue.offer(node.right);
            }
            depth++;
        }
        return depth;
    }
}

@@IDEA
迭代 DFS：栈里存 (节点, 深度) 对做前序遍历，过程中记录最大深度。O(n)/O(h)，展示「栈存状态对」的通用技巧。

class Solution {
    public int maxDepth(TreeNode root) {
        if (root == null) return 0;
        Deque<Object[]> stack = new ArrayDeque<>(); // {节点, 深度}
        stack.push(new Object[]{root, 1});
        int best = 0;
        while (!stack.isEmpty()) {
            Object[] top = stack.pop();
            TreeNode node = (TreeNode) top[0];
            int depth = (Integer) top[1];
            best = Math.max(best, depth);
            if (node.left != null) stack.push(new Object[]{node.left, depth + 1});
            if (node.right != null) stack.push(new Object[]{node.right, depth + 1});
        }
        return best;
    }
}

class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        TreeNode t = root.left;                 // 交换左右孩子
        root.left = invertTree(root.right);
        root.right = invertTree(t);
        return root;
    }
}

class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) return null;
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode node = queue.poll();
            TreeNode t = node.left;   // 交换左右孩子
            node.left = node.right;
            node.right = t;
            if (node.left != null) queue.offer(node.left);
            if (node.right != null) queue.offer(node.right);
        }
        return root;
    }
}

@@IDEA

class Solution {
    public boolean isSymmetric(TreeNode root) {
        return mirror(root, root);
    }
    private boolean mirror(TreeNode a, TreeNode b) {
        if (a == null && b == null) return true;
        if (a == null || b == null) return false;
        return a.val == b.val
                && mirror(a.left, b.right)   // 外侧比较
                && mirror(a.right, b.left);  // 内侧比较
    }
}

@@IDEA

class Solution {
    public boolean isSymmetric(TreeNode root) {
        Deque<TreeNode> queue = new ArrayDeque<>();
        queue.offer(root);
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode a = queue.poll(), b = queue.poll();
            if (a == null && b == null) continue;
            if (a == null || b == null || a.val != b.val) return false;
            queue.offer(a.left);  // 镜像成对入队
            queue.offer(b.right);
            queue.offer(a.right);
            queue.offer(b.left);
        }
        return true;
    }
}

@@IDEA

class Solution {
    public boolean isSymmetric(TreeNode root) {
        List<Integer> l = new ArrayList<>(), r = new ArrayList<>();
        inorder(root.left, l, true);   // 左子树：中序
        inorder(root.right, r, false); // 右子树：反中序
        return l.equals(r);
    }
    private void inorder(TreeNode node, List<Integer> res, boolean normal) {
        if (node == null) {
            res.add(null); // 占位保证结构一致
            return;
        }
        if (normal) {
            inorder(node.left, res, true);
            res.add(node.val);
            inorder(node.right, res, true);
        } else {
            inorder(node.right, res, false);
            res.add(node.val);
            inorder(node.left, res, false);
        }
    }
}
@@PY
class Solution:
    def isSymmetric(self, root: Optional[TreeNode]) -> bool:
        left_seq, right_seq = [], []

        def inorder(node, res, normal):
            if not node:
                res.append(None)  # 占位保证结构一致
                return
            nxt = (node.left, node.right) if normal else (node.right, node.left)
            inorder(nxt[0], res, normal)
            res.append(node.val)
            inorder(nxt[1], res, normal)

        inorder(root.left, left_seq, True)     # 左子树：中序
        inorder(root.right, right_seq, False)  # 右子树：反中序
        return left_seq == right_seq

    public TreeNode sortedArrayToBST(int[] nums) {
        int n = nums.length;
        if (n == 0) return null;
        // 记录 (父节点, 挂左还是右, lo, hi)
        Deque<Object[]> queue = new ArrayDeque<>();
        int lo = 0, hi = n - 1, mid = (lo + hi) / 2;
        TreeNode root = new TreeNode(nums[mid]);
        queue.offer(new Object[]{root, 0, lo, mid - 1});
        queue.offer(new Object[]{root, 1, mid + 1, hi});
        while (!queue.isEmpty()) {
            Object[] job = queue.poll();
            TreeNode parent = (TreeNode) job[0];
            boolean right = (Integer) job[1] == 1;
            int l = (Integer) job[2], r = (Integer) job[3];
            if (l > r) continue;

            TreeNode node = new TreeNode(nums[m]);
            if (right) parent.right = node;
            else parent.left = node;
            queue.offer(new Object[]{node, 0, l, m - 1});
            queue.offer(new Object[]{node, 1, m + 1, r});
        }
        return root;
    }

            if (cur.val <= prev) return false; // 必须严格递增

            cur = cur.right;

        return true;

                    inIdx++;

                parent.right = node;    // 挂右子树
                stack.push(node);
            }

class Solution {
    private final List<Long> path = new ArrayList<>();
    private int ans = 0;

    public int pathSum(TreeNode root, int targetSum) {
        dfs(root, targetSum);
        return ans;
    }
    private void dfs(TreeNode node, long target) {
        if (node == null) return;
        long cur = path.isEmpty() ? node.val : path.get(path.size() - 1) + node.val;
        for (long pre : path) {          // 枚举起点前缀
            if (cur - pre == target) ans++;
        }
        if (cur == target) ans++;        // 从根出发
        path.add(cur);
        dfs(node.left, target);
        dfs(node.right, target);
        path.remove(path.size() - 1);    // 回溯
    }
}

@@IDEA
父指针法：DFS 记录每个节点的父节点；从 p 向上收集祖先链到集合，再从 q 向上走，第一个命中集合的即 LCA。O(n)/O(n)，不用递归推导。

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        Deque<TreeNode> stack = new ArrayDeque<>();
        parent.put(root, null);
        stack.push(root);
        while (!parent.containsKey(p) || !parent.containsKey(q)) { // 记录父指针
            TreeNode node = stack.pop();
            if (node.left != null) { parent.put(node.left, node); stack.push(node.left); }
            if (node.right != null) { parent.put(node.right, node); stack.push(node.right); }
        }
        Set<TreeNode> ancestors = new HashSet<>();
        for (TreeNode a = p; a != null; a = parent.get(a)) {
            ancestors.add(a); // p 的祖先链
        }
        for (TreeNode a = q; a != null; a = parent.get(a)) {
            if (ancestors.contains(a)) return a; // 首个公共祖先
        }
        return null;
    }
}

@@IDEA
路径比对：分别 DFS 求根到 p、根到 q 的路径（回溯保存），从前往后最后一个相同的节点即 LCA。O(n)/O(n)，思路最直白。

class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        List<TreeNode> pathP = new ArrayList<>(), pathQ = new ArrayList<>();
        findPath(root, p, pathP); // 根到 p 的路径
        findPath(root, q, pathQ); // 根到 q 的路径
        TreeNode lca = null;
        int n = Math.min(pathP.size(), pathQ.size());
        for (int i = 0; i < n; i++) {
            if (pathP.get(i) == pathQ.get(i)) lca = pathP.get(i); // 最后相同节点
            else break;
        }
        return lca;
    }
    private boolean findPath(TreeNode node, TreeNode target, List<TreeNode> path) {
        if (node == null) return false;
        path.add(node);
        if (node == target) return true;
        if (findPath(node.left, target, path) || findPath(node.right, target, path)) {
            return true;
        }
        path.remove(path.size() - 1); // 回溯
        return false;
    }
}

class Solution {
    private int best = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        dfs(root);
        return best;
    }
    private int dfs(TreeNode node) {
        if (node == null) return 0;
        int l = Math.max(dfs(node.left), 0);   // 负贡献截断
        int r = Math.max(dfs(node.right), 0);
        best = Math.max(best, node.val + l + r); // 以 node 为顶的路径
        return node.val + Math.max(l, r);        // 向上只能选一侧

@@IDEA
对照版：对每个节点作为「拐点」，单独计算左右两侧最大向下链（重复计算），更新经过它的路径和。O(n²) 最坏，帮助理解定义，实际用解法一。

class Solution {
    private int best = Integer.MIN_VALUE;

    public int maxPathSum(TreeNode root) {
        walk(root);
        return best;
    }
    private void walk(TreeNode node) { // 枚举每个拐点
        if (node == null) return;
        int l = Math.max(0, chain(node.left));  // 左侧最大链
        int r = Math.max(0, chain(node.right)); // 右侧最大链
        best = Math.max(best, node.val + l + r);
        walk(node.left);
        walk(node.right);
    }
    private int chain(TreeNode node) { // 从 node 向下的最大链和（至少含 node）
        if (node == null) return Integer.MIN_VALUE;
        int bestChild = Math.max(chain(node.left), chain(node.right));
        return node.val + Math.max(0, bestChild);
    }
}
