@@TITLE: 无重复字符的最长子串
@@DIFF: 中等
@@CATEGORY: 滑动窗口
@@TAGS: 哈希表;字符串;滑动窗口
@@URL: https://leetcode.cn/problems/longest-substring-without-repeating-characters/
@@DESC
给定一个字符串 s，请你找出其中不含有重复字符的最长子串的长度。

示例 1：
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3。

示例 2：
输入：s = "bbbbb"
输出：1

示例 3：
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3。请注意，你的答案必须是子串的长度，"pwke" 是一个子序列，不是子串。

提示：
0 <= s.length <= 5 * 10^4
s 由英文字母、数字、符号和空格组成
给定一个字符串 s，请你找出其中不含有重复字符的最长子串的长度（子串是连续的）。
示例：s = "abcabcbb" → 输出 3（无重复最长子串 "abc"）；s = "bbbbb" → 输出 1。
@@SOLUTION: 方法一：滑动窗口 + 哈希表（推荐）
@@IDEA
滑动窗口 + 哈希表记录每个字符最后出现的下标；右指针遇到重复字符时，左指针直接跳到「重复字符上次出现位置+1」，不用一格一格退。时间 O(n)。
@@JAVA
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Map<Character, Integer> last = new HashMap<>(); // 字符 -> 最后一次下标
        int left = 0, best = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            if (last.containsKey(c) && last.get(c) >= left) {
                left = last.get(c) + 1; // 左指针跳到重复字符之后
            }
            last.put(c, right);
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}

@@SOLUTION: 方法二：滑动窗口 + Set 逐格收缩
@@IDEA
窗口内用 Set 判重：右指针扩张遇到重复时，左指针逐格右移并从 Set 删除字符，直到删掉重复的那个。每字符最多进出各一次，仍为 O(n)，写法更直白。
@@JAVA
class Solution {
    public int lengthOfLongestSubstring(String s) {
        Set<Character> window = new HashSet<>();
        int left = 0, best = 0;
        for (int right = 0; right < s.length(); right++) {
            char c = s.charAt(right);
            while (window.contains(c)) {     // 有重复则收缩
                window.remove(s.charAt(left++));
            }
            window.add(c);
            best = Math.max(best, right - left + 1);
        }
        return best;
    }
}

@@SOLUTION: 方法三：暴力 + 哈希判重
@@IDEA
枚举每个起点，向右扩展并用 HashSet 判重，直到出现重复字符为止，记录最长长度。O(n²)，仅作对照。
@@JAVA
class Solution {
    public int lengthOfLongestSubstring(String s) {
        int best = 0;
        for (int i = 0; i < s.length(); i++) {
            Set<Character> seen = new HashSet<>();
            int j = i;
            while (j < s.length() && seen.add(s.charAt(j))) j++; // 无重则扩展
            best = Math.max(best, j - i);
        }
        return best;
    }
}

@@DIFF: 中等

@@TAGS: 哈希表;字符串;滑动窗口
@@URL: https://leetcode.cn/problems/find-all-anagrams-in-a-string/
@@DESC
给定两个字符串 s 和 p，找到 s 中所有 p 的异位词子串，返回这些子串的起始索引。不考虑答案输出的顺序。

异位词指字母相同，但排列不同的字符串。

示例 1：
输入：s = "cbaebabacd", p = "abc"
输出：[0,6]
解释：起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。

示例 2：
输入：s = "abab", p = "ab"
输出：[0,1,2]

提示：
1 <= s.length, p.length <= 3 * 10^4
s 和 p 仅包含小写字母
给定两个字符串 s 和 p，找到 s 中所有 p 的异位词子串，返回这些子串的起始索引。不考虑答案输出的顺序。
示例：s = "cbaebabacd", p = "abc" → 输出 [0,6]（"cba" 与 "bac" 均是 "abc" 的异位词）。
@@SOLUTION: 方法一：固定窗口计数差（推荐）
@@IDEA
固定长度为 len(p) 的滑动窗口，维护计数差数组 cnt = 窗口计数 - p 计数，并用 diff 记录非零字母种数；每次滑动只动进出两个字符，diff 为 0 即异位词。时间 O(n)。
@@JAVA
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        int m = s.length(), n = p.length();
        if (m < n) return res;
        int[] cnt = new int[26];
        for (int i = 0; i < n; i++) {
            cnt[s.charAt(i) - 'a']++;
            cnt[p.charAt(i) - 'a']--;
        }
        int diff = 0; // 计数非 0 的字母种数
        for (int d : cnt) if (d != 0) diff++;
        if (diff == 0) res.add(0);
        for (int i = n; i < m; i++) {
            int in = s.charAt(i) - 'a', out = s.charAt(i - n) - 'a';
            if (cnt[in] == 0) diff++;
            cnt[in]++;
            if (cnt[in] == 0) diff--;
            if (cnt[out] == 0) diff++;
            cnt[out]--;
            if (cnt[out] == 0) diff--;
            if (diff == 0) res.add(i - n + 1);
        }
        return res;
    }
}

class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        m, n = len(s), len(p)
        if m < n:
            return []
        res = []
        need = Counter(p)
        window = Counter(s[:n])
        if window == need:
            res.append(0)
        for i in range(n, m):
            window[s[i]] += 1
            window[s[i - n]] -= 1
            if window[s[i - n]] == 0:
                del window[s[i - n]]
            if window == need:      # Counter 相等即异位词
                res.append(i - n + 1)
        return res
@@SOLUTION: 方法二：窗口计数 + 每步比较（写法更直白）
@@IDEA
维护窗口的 26 位计数数组，每滑动一步与 p 的计数数组直接比较（Java 用 Arrays.equals，Python 用 Counter 相等）。O(26n)，常数略大但代码最短。
@@JAVA
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        int m = s.length(), n = p.length();
        if (m < n) return res;
        int[] window = new int[26], need = new int[26];
        for (char c : p.toCharArray()) need[c - 'a']++;
        for (int i = 0; i < m; i++) {
            window[s.charAt(i) - 'a']++;      // 右端进
            if (i >= n) window[s.charAt(i - n) - 'a']--; // 左端出
            if (i >= n - 1 && Arrays.equals(window, need)) {
                res.add(i - n + 1);
            }
        }
        return res;
    }
}

@@SOLUTION: 方法三：暴力枚举 + 排序比较
@@IDEA
枚举 s 的每个长度为 len(p) 的子串，排序后与排序好的 p 比较。O(n·k log k)，大输入会超时，仅作对照。
@@JAVA
class Solution {
    public List<Integer> findAnagrams(String s, String p) {
        List<Integer> res = new ArrayList<>();
        int m = s.length(), n = p.length();
        char[] target = p.toCharArray();
        Arrays.sort(target);
        for (int i = 0; i + n <= m; i++) {
            char[] sub = s.substring(i, i + n).toCharArray();
            Arrays.sort(sub); // 子串排序后与 p 比较
            if (Arrays.equals(sub, target)) res.add(i);
        }
        return res;
    }
}
