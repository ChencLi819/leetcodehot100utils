class Solution {
    public int singleNumber(int[] nums) {
        int x = 0;
        for (int v : nums) x ^= v; // 成对抵消
        return x;
    }
}

class Solution {
    public int singleNumber(int[] nums) {
        Set<Integer> set = new HashSet<>();
        long setSum = 0, total = 0;
        for (int x : nums) {
            total += x;
            if (set.add(x)) setSum += x; // 只累加一次
        }
        return (int) (2 * setSum - total); // 数学抵消
    }
}

class Solution {
    public int majorityElement(int[] nums) {
        int candidate = nums[0], votes = 0;
        for (int x : nums) {
            if (votes == 0) candidate = x;    // 换候选
            votes += (x == candidate) ? 1 : -1;
        }
        return candidate;
    }
}

@@IDEA

class Solution {
    public void sortColors(int[] nums) {
        int p0 = 0, i = 0, p2 = nums.length - 1;
        while (i <= p2) {
            if (nums[i] == 0) {
                swap(nums, p0++, i++);
            } else if (nums[i] == 2) {
                swap(nums, p2--, i); // 换回的数需重判，i 不动
            } else {
                i++;
            }
        }
    }
    private void swap(int[] a, int x, int y) {
        int t = a[x]; a[x] = a[y]; a[y] = t;
    }
}

@@DESC
整数数组的一个 排列 就是将其所有成员成员进行序列排序。

整数数组的 下一个排列 是指其整数的下一个字典序更大的排列。更正式地，如果数组的全部排列按字典序排序，则数组的下一个排列就是按字典序排序后紧跟在当前排列之后的排列。如果该数组没有更大的排列，则将其重新排列成字典序最小的排列（即整体升序排列）。

必须 原地 修改，只允许使用额外常数空间。

示例 1：
输入：nums = [1,2,3]
输出：[1,3,2]

示例 2：
输入：nums = [3,2,1]
输出：[1,2,3]

示例 3：
输入：nums = [1,1,5]
输出：[1,5,1]

提示：
1 <= nums.length <= 100
0 <= nums[i] <= 100
将整数数组重排为字典序中的下一个更大排列；不存在更大排列时（已是最大）重排为最小升序。必须原地修改、只用常数空间。
示例：nums = [1,2,3] → [1,3,2]；nums = [3,2,1] → [1,2,3]。
@@SOLUTION: 方法一：找谷底 + 右侧交换 + 后缀反转（推荐）
@@IDEA
标准解：从右找第一个升序对（i 处变矮），再从右找第一个大于 nums[i] 的数交换，最后反转 i 之后必为降序的后缀。O(n)/O(1)，三步缺一不可。
@@JAVA
class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length, i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--; // 找谷底
        if (i >= 0) {
            int j = n - 1;
            while (nums[j] <= nums[i]) j--;           // 右侧第一个更大数
            swap(nums, i, j);
        }
        reverse(nums, i + 1, n - 1);                  // 后缀反转成升序
    }
    private void swap(int[] a, int x, int y) {
        int t = a[x]; a[x] = a[y]; a[y] = t;
    }
    private void reverse(int[] a, int l, int r) {
        while (l < r) swap(a, l++, r--);
    }
}

@@IDEA

class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        // 从最右位开始，找到能被「增大」的最高位
        for (int pos = n - 2; pos >= -1; pos--) {
            if (pos == -1) { // 整个数组递减：重排为升序
                Arrays.sort(nums);
                return;
            }
            // 在 pos 右侧找大于 nums[pos] 的最小数
            int best = -1;
            for (int j = pos + 1; j < n; j++) {
                if (nums[j] > nums[pos]
                        && (best == -1 || nums[j] < nums[best])) {
                    best = j;
                }
            }
            if (best != -1) {
                swap(nums, pos, best);            // 增大该位
                Arrays.sort(nums, pos + 1, n);    // 后缀最小化
                return;
            }
        }
    }
    private void swap(int[] a, int x, int y) {
        int t = a[x]; a[x] = a[y]; a[y] = t;
    }
}

给定一个包含 n + 1 个整数的数组 nums，其数字都在 [1, n] 范围内（包括 1 和 n），可知至少存在一个重复的整数。

示例 1：
输入：nums = [1,3,4,2,2]

示例 2：
输入：nums = [3,1,3,4,2]
输出：3

提示：

nums.length == n + 1
1 <= nums[i] <= n
nums 中 只有一个整数 出现 两次或多次，其余整数均只出现一次

进阶：如何证明 nums 中至少存在一个重复的数字？你可以设计一个线性级时间复杂度、O(1) 额外空间的算法吗？
给定含 n+1 个整数的数组 nums，数字都在 [1, n] 范围内，只有一个重复数字（可能重复多次）。找出这个重复数。不能修改数组、只能用 O(1) 额外空间。

@@SOLUTION: 方法一：Floyd 判圈（推荐，O(1) 空间）
@@IDEA
Floyd 判圈：把「下标→值」看作链表 next 指针，nums 中必存在环且重复数是入环点；快慢相遇后一指针回起点，同速前进再次相遇处即答案。O(n)/O(1)，不动数组。
@@JAVA
class Solution {
    public int findDuplicate(int[] nums) {
        int slow = nums[0], fast = nums[nums[0]];
        while (slow != fast) {     // 相遇在环内
            slow = nums[slow];
            fast = nums[nums[fast]];
        }
        slow = 0;                  // 回到起点
        while (slow != fast) {     // 同速找入环点
            slow = nums[slow];
            fast = nums[fast];
        }
        return slow;
    }
}

class Solution {
    public int findDuplicate(int[] nums) {
        int l = 1, r = nums.length - 1; // 值域
        while (l < r) {
            int mid = l + (r - l) / 2;
            int cnt = 0;
            for (int x : nums) {
                if (x <= mid) cnt++; // 统计 <= mid 的个数
            }
            if (cnt > mid) r = mid;  // 重复数在左半
            else l = mid + 1;        // 在右半
        }
        return l;
    }
}

        l, r = 1, len(nums) - 1  # 值域
        while l < r:
            mid = (l + r) // 2
            cnt = sum(1 for x in nums if x <= mid)  # 统计 <= mid
            if cnt > mid:   # 重复数在左半
                r = mid
            else:
                l = mid + 1
        return l
@@SOLUTION: 方法三：哈希集合（不满足空间要求，作对照）
@@IDEA
哈希集合对照：逐个访问存 Set，第一个重复出现的即答案。O(n)/O(n)，最简单但不满足 O(1) 空间要求。
@@JAVA
class Solution {
    public int findDuplicate(int[] nums) {
        Set<Integer> seen = new HashSet<>();
        for (int x : nums) {
            if (!seen.add(x)) return x; // 首个重复
        }
        return -1;
    }
}

class Solution:
    def findDuplicate(self, nums: List[int]) -> int:
        seen = set()
        for x in nums:
            if x in seen:  # 首个重复
                return x
            seen.add(x)
        return -1
