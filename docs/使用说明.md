# 使用说明

## 界面布局

应用启动后分为三个区域：

- **左侧**：题目列表（100 题，含分类彩点、完成 ✓、收藏 ★ 标记），顶部提供搜索框与「难度 / 分类」筛选，另有「只看未完成」「只看收藏」开关
- **中间**：三个选项卡——题目描述、参考题解、我的作答
- **右侧**：可折叠的笔记栏（点击顶部「笔记」按钮展开 / 收起，按题目自动保存）
- **底部**：刷题进度条（含难度分布统计与收藏数）

## 做题工作流

### 1. 选题与看题

在左侧列表选中题目后，「题目描述」选项卡展示完整官方题面（含示例与数据范围）；「参考题解」提供 **3 种不同思路**的解法，每种包含解题思路、复杂度分析与 Java / Python 双语言代码，可在顶部下拉框切换方法。

### 2. 生成训练骨架

在「我的作答」点击 **恢复模板**，生成本题专属的训练骨架：

- `Main` 类内已写好**调用本题方法的示例代码**（构造输入 → 调用 → 打印期望结果）
- 题解类（如 `class Solution`）与方法签名已定义好，方法体为 TODO

直接点「运行」会提示 `UnsupportedOperationException("TODO")`——这就是你的起点。

### 3. 实现与验证

在骨架的方法体内实现你的解法，点 **▶ 运行**（或 Ctrl+Enter）：

- Java 代码由 JDK 内置编译器编译后运行；常用 import 与 `TreeNode`/`ListNode`/`Node` 数据结构已内置，可直接使用力扣风格写法
- Python 代码由本机 Python 解释器运行；`typing` 等常用模块已预置
- 运行输出显示在下方的浅色控制台；编译错误会标注行号（行号与编辑器一致）

卡壳时可点 **载入题解代码**：参考实现会**替换题解类骨架**（保留你的 main 函数），并自动补全缺失的 import，随后运行即可看到正确输出。

### 4. 打卡与笔记

- 通过后点击 **标记完成**，底部进度条与统计同步更新
- 觉得经典的题可点 **☆ 收藏**，配合顶部「只看收藏」快速复习
- 右侧笔记栏记录解题总结，按题目独立保存（1.2 秒防抖自动保存，切换题目 / 收起 / 关闭应用前均会落盘）

## 快捷键

| 快捷键 | 作用 |
|--------|------|
| `Ctrl+Enter` | 运行答题区代码 |
| `Enter` | 展开快速输入模板 / 换行（自动继承缩进，行尾 `{` 或 `:` 自动加一层） |
| `Tab` / `Shift+Tab` | 缩进 / 反缩进（选中多行整体生效，可作为全选后的批量缩进） |
| `Ctrl+Z` | 撤销上一步操作（连续打字整段撤回；粘贴、载入、缩进等各为独立步骤） |
| `Ctrl+Y` / `Ctrl+Shift+Z` | 重做 |
| `Ctrl+A` | 全选 |
| `Ctrl+C` / `Ctrl+X` / `Ctrl+V` | 复制 / 剪切 / 粘贴 |
| `Ctrl+滚轮` | 缩放当前内容区字号（10~30） |

**快速输入模板**（输入缩写后按 `Enter`，`|` 为展开后光标位置）：

| 缩写 | 展开结果 |
|------|----------|
| `sout` | `System.out.println(\|);` |
| `souf` | `System.out.printf(\|);` |
| `serr` | `System.err.println(\|);` |
| `psvm` / `main` | main 方法骨架 |
| `fori` | `for (int i = 0; i < \|; i++) { }` |
| `for` / `iter` / `foreach` | 增强 for 循环 |
| `ifn` / `inn` | `if (x == null)` / `if (x != null)` |
| `tryc` | try-catch 骨架 |
| `thr` | `throw new \|;` |
| `psf` / `psfi` / `psfs` | `public static final` 常量 |
| `alist` / `hmap` | `List` / `Map` 集合初始化 |

**后缀补全**（输入表达式与后缀后按 `Enter`）：

| 输入 | 展开结果 |
|------|----------|
| `100.sout` | `System.out.println(100);` |
| `"msg".serr` | `System.err.println("msg");` |
| `n.fori` | `for (int i = 0; i < n; i++) { }` |
| `list.iter` | `for (var item : list) { }` |
| `expr.nn` | `if (expr != null) { }` |
| `expr.var` | `var x = expr;` |
| `expr.return` | `return expr;` |

## 数据与存储

| 数据 | 位置 | 说明 |
|------|------|------|
| 刷题进度、收藏 | `~/.hot100/progress.properties` | 完成打卡与收藏标记 |
| 各题作答代码 | `~/.hot100/answers.properties` | 按题号 + 语言保存 |
| 各题笔记 | `~/.hot100/notes.properties` | 按题号保存 |

以上均在本机用户目录下，更新 / 重装 / 拷贝应用不会丢失；将 `~/.hot100` 复制到新机器即可迁移全部数据。

## 常见问题

**Q：运行 Python 提示「未找到 Python 解释器」？**
安装 Python 3 并勾选「Add to PATH」，或确认 `python` 命令在命令行可用后重启应用。应用也会自动探测 `%USERPROFILE%\.workbuddy\binaries\python\versions\` 下的托管解释器。

**Q：Java 提示「未找到 class Main」？**
答题区代码必须包含 `public class Main` 与 `main` 方法（作为程序入口）。点「恢复模板」可重新生成本题骨架。

**Q：编译报错行号对不上？**
行号已自动换算为编辑器中的真实行号；若使用载入的题解，报错行号同样对应编辑器当前内容。

**Q：进度会丢吗？**
不会。进度 / 作答 / 笔记都在 `~/.hot100` 下，与安装目录无关；重装、升级、拷贝应用均不影响。

**Q：如何扩充题库？**
在 `data` 目录按现有格式新增 `.txt` 文件（或向现有文件追加 `@@PROBLEM` 段落），重启应用自动加载。每题至少提供 3 种解法才能通过数据校验。
